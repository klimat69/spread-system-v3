# Терминал MEXC — простая инструкция

## Шапка

| Надпись | Что это |
|---------|---------|
| **WS подключён** | Программа видит свой сервер на компьютере. Это не биржа. |
| **Поток: OK** | С биржи MEXC приходят стакан и сделки. **Без этого бот не торгует.** |
| **Поток: Проблема** | Данные с MEXC не готовы (пустой стакан, нет ленты, обрыв). |
| **Автоторговля** | Разрешение анализировать рынок и (в Paper) симулировать сделки. |
| **Старт / Стоп** | Включить или выключить «мозг» бота. |

## Рынки (слева)

- **Фьючерсы** — как раздел GOLD Futures на сайте MEXC.
- **USDT** — для золота на фьючерсах нужен USDT, не USDC.
- **GOLD Futures** — выбирает контракт XAUT/USDT (стакан `XAUT_USDT` на бирже).
- **Пресет: демо GOLD** — Paper, мягкие сигналы, автоторговля; потом **Сохранить** и **Старт**.

## График TradingView (центр)

- Кнопки **1 сек / 5 сек / 1 мин** — только для просмотра.
- Бот торгует по **стакану и ленте справа**, не по картинке графика.
- На MEXC сайт может показывать 1s; у виджета TradingView 1s доступен не для всех пар.
- **Задержка на графике нормальна:** TradingView — чужой виджет, он отстаёт от биржи на секунды. У бота свой поток с MEXC; смотрите метрику **«Задержка потока MEXC → экран»** (обычно сотни миллисекунд, не секунды).

## Обновления без пересборки на вашем ПК

Вам **не нужно** собирать `.dmg` / `.exe` локально.

1. Изменения попадают в GitHub (ветка `main`).
2. Создаётся тег версии, например `v3.1.6` (номер должен совпадать с версией в `desktop/package.json`).
3. GitHub Actions **Desktop Release** собирает macOS и Windows и публикует файлы в [Releases](https://github.com/klimat69/spread-system-v3/releases).
4. Установленное приложение раз в ~30 минут проверяет обновления и показывает: «Доступно обновление» → загрузка → «Перезапустить».

**Важно:** автообновление работает только в **установленной** версии из релиза (не `npm run dev`). Если когда-то ставили очень старую сборку без `app-update.yml`, один раз поставьте свежий установщик с Releases — дальше обновления пойдут сами.

Проверка вручную: в меню приложения или баннер «Обновление» вверху экрана.

## Paper (демо)

- API ключи **не нужны** для просмотра рынка и симуляции.
- Сделки **не уходят на биржу** — смотрите блок **«События Paper (dry-run)»** внизу.
- Нужно: **Старт** + **Автоторговля** + **Поток: OK** + ненулевые bid/ask.
- Включите **«Мягкие сигналы (демо)»** или пресет GOLD, если сделок долго нет.

## Скальп (simple_scalp)

| Поле | Простыми словами |
|------|------------------|
| Мин. спред | Насколько цены bid/ask разошлись, чтобы было интересно. |
| Мин. дисбаланс | Одна сторона стакана заметно тяжелее другой. |
| Мин. агрессия ленты | В ленте много рыночных покупок или продаж. |
| Отмена устаревшего ордера | Через сколько секунд забыть старый ордер (live). |
| Перестановка при сдвиге | Если цена ушла на N bps — переставить ордер. |

## Стратегия

| Поле | Простыми словами |
|------|------------------|
| Макс. удержание | Сколько секунд максимум «держать» позицию в логике бота. |
| Макс. открытых ордеров | Сколько ордеров одновременно (live). |
| Пауза между входами | Отдых между новыми попытками. |
| Выход по дисбалансу | Выйти, если стакан выровнялся. |
| Порог агрессии входа | Насколько сильная лента нужна для входа. |
| Устаревание стакана | Не входить, если стакан старше N секунд. |

## Риск

| Поле | Простыми словами |
|------|------------------|
| Макс. дневной убыток | Стоп-лимит убытка за день. |
| Макс. размер позиции | Лимит размера одной сделки. |
| Макс. экспозиция | Лимит общей позиции. |
| Пауза после убытка | Пауза после минусовой сделки. |

## Частые причины «Поток: Проблема»

1. Выбран USDC вместо USDT для GOLD futures.
2. Не сохранён конфиг после смены пары.
3. Первые 10–20 секунд после старта — подождите «OK».
4. Смотрите лог: `~/Library/Application Support/spread-system-v3-desktop/logs/backend.log` (macOS).

## Логи

- macOS: `~/Library/Application Support/spread-system-v3-desktop/logs/`
- Windows: `%APPDATA%\spread-system-v3-desktop\logs\`
